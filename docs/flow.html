How the concierge flows

The top diagram shows how a code change reaches production. The bottom one shows what happens to a single chat message once the app is live.

From commit to production

Every push runs .github/workflows/pipeline.yml. A failing check stops the run, and nothing after it runs.

What happens to one chat message

Each message goes to exactly one specialist agent. The reply is written only from facts the tools return, so it can't make up prices, flights or entry rules.
